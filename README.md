# VAPT Dashboard - EPL

This repository contains the source code and assets for the Vulnerability Assessment and Penetration Testing (VAPT) Dashboard developed for EPL Limited.

## Features

- Interactive dashboard displaying vulnerability assessment data using pie and bar charts.
- Modules for VAPT, ASM, BAS, and Red Teaming.
- Data visualization with Chart.js.
- Reports section for downloading PDF and Excel report files.
- Dark/light mode toggle.

## Folder Structure

- `index.html` - Main dashboard HTML file.
- `ASM/` - Contains ASM-related report documents.
- `BAS/` - Contains BAS-related report documents.
- `JS/` *(optional)* - JavaScript libraries or custom scripts.
- `CSS/` *(optional)* - Stylesheets.

## How to Use

1. Clone this repository.
2. Open `index.html` in a modern web browser.
3. Navigate through the dashboard to explore different modules and reports.
4. Upload reports and update data as needed.
